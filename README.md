# expenseTracking_usingReact

## 🛠 Tech Stack

## ✨ Frontend

| Technology | Purpose |
|------------|---------|
| **React** | Builds the user interface using reusable components. |
| **TypeScript** | Adds static typing to JavaScript for better code quality and maintainability. |
| **Vite** | Fast development server and build tool for React applications. |
| **Tailwind CSS** | Utility-first CSS framework for creating responsive and modern user interfaces. |
| **React Router DOM** | Handles client-side routing and navigation between pages. |
| **Axios** | Sends HTTP requests to communicate with the Laravel REST API. |
| **Recharts** | Displays interactive charts for expenses, income, and financial reports. |

## ✨ Backend

| Technology | Purpose |
|------------|---------|
| **Laravel** | Handles business logic, API endpoints, authentication, and database operations. |
| **Laravel Sanctum** | Provides secure authentication and API token management. |
| **RESTful API** | Enables communication between the React frontend and Laravel backend using JSON. |

## ✨ Database

| Technology | Purpose |
|------------|---------|
| **MySQL 8** | Stores application data such as users, expenses, income, budgets, and categories. |

## ✨ DevOps & Development Tools

| Technology | Purpose |
|------------|---------|
| **Docker & Docker Compose** | Creates a consistent development environment and runs MySQL in a container. |
| **Git & GitHub** | Tracks source code changes and manages version control. |
| **Postman** | Tests and verifies REST API endpoints during development. |
| **DBeaver** | Database management tool used to view and manage MySQL data. |
| **Visual Studio Code** | Primary code editor for frontend and backend development. |
